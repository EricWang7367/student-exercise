# Acceptance test scenarios

## Premise

Create a simple title register, with entries and proprietors.

## Functionality

(CRUD ops)

- Create a register (with an ID of some sort)
- View a register
- Update a register
- Archive a register
- Search for registers

- Add an entry to a register
- View an entry
- Update an entry
- Delete/archive an entry
- Search for entries

## Acceptance criteria

- Register has a unique name (user provided)
- Register has an empty array of entries
- Validation of invalid details provides error message
- Creating a duplicate register name fails validation
- Validation of entry text?
- Validation of entry properties/metadata
